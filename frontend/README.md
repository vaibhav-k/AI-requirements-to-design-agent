# Frontend

React + Vite + TypeScript app for the requirements → architecture agent.

See the root [`README.md`](../README.md#frontend) — the "Frontend" section
covers what this app does, how to run it, and how to set up the Entra ID
app registration it needs for sign-in.

Quick start:

```bash
npm install
cp .env.example .env   # fill in the values, see root README
npm run dev
```
